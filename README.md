# CloudNine
Project for fallen
Cloud Nine

A soft, expressive, physical companion

Cloud Nine is a mechanical design and prototyping project focused on creating a soft, cloud-inspired physical character. The project explores the intersection of product design, CAD modelling, material selection and physical prototyping.

1. Project Overview

Cloud Nine is designed as a small, soft-bodied character with an expressive OLED face. Its visual identity is inspired by clouds, simplicity and minimalistic character design.

The objective is to transform a digital concept into a functional physical prototype within a two-week development period.

2. Inspiration

The project draws inspiration from the visual softness of clouds and the idea of giving an inanimate object a distinct personality through its appearance.

3. Objectives

Develop a distinctive character identity.

Create a dimensionally accurate CAD model.

Explore suitable materials for a soft exterior.

Plan component placement and internal structure.

Build a physical prototype.

Document the complete design and development process.
